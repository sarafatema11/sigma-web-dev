JavaScript Loops

Definition of Loops :

A loop in JavaScript is used to execute a block of code repeatedly until a specified condition becomes false.

Types of Loops in JavaScript

There are mainly 5 types of loops in JavaScript:

  1. For Loop
  2. While Loop
  3. Do While Loop
  4. For In Loop
  5. For Of Loop

1. For Loop

Definition:

A for loop is used to execute a block of code repeatedly when the number of iterations is known.

Syntax:

        
Ex:1 of Syntax

for (initialization; condition; increment/decrement) {
    // Code to execute
}

 
Ex:2 of Syntax


for(statement1, statement2,statement3){
    //code to be execute
}


Expplain :


Statement 1 (Initialization): Initializes the loop variable. It executes only once.
Example: let i = 1;

Statement 2 (Condition): Checks whether the condition is true or false. If true, the loop executes; if false, it stops.
Example: i <= 5;

Statement 3 (Increment/Decrement): Increases or decreases the loop variable after each iteration.
Example: i++



Working process Method: Initialization → Condition Check → Execute Code → Increment/Decrement → Condition Check Again.

Example:


for (let i = 0; i <5; i++) {     
    console.log(a + i);            
}

Output:

1
2
3
4
5

Important Points:

  • Initialization is executed only once.
  • Condition is checked before every iteration.
  • Increment or decrement updates the variable.

2. For In Loop

Definition:

A for in loop is used to iterate over the enumerable property keys of an object.

A for in loop is used to access the keys (property names) of an object one by one.

Syntax:

for (let key in object) {
    // Code to execute
}

Example:

let obj ={
    name: "Harry",          
    role : "Programmer",
    Company: "CodeWithharry Ai" 
}

for (const key in obj) {
    const element = obj[key];
    console.log(key, element) 
}

Output (Console):

name Harry
role Programmer
Company CodeWithharry Ai

Here we can write Both Key & element & only Key & only element we can write also Any onne of these.

Important Points:

  • It is mainly used with objects.
  • It returns property keys.
  • Object values can be accessed using object[key].

3. For Of Loop

Definition:

A for of loop is used to iterate over the values of iterable objects such as arrays and strings.

A for of loop is used to access the values of an array or string one by one.

Syntax:

for (let value of iterable) {
    // Code to execute
}

Example 1:

let fruits = ["Apple", "Banana", "Mango"];

for (let fruit of fruits) {
    console.log(fruit);
}

Output (Console):

Apple
Banana
Mango

Example 2 :

        for (const c of "Harry") {   
    console.log(c)  
}

Output (Console):

        H 
        a 
        r 
        r 
        y

Important Points:

  • It is used with arrays, strings and other iterables.
  • It returns values instead of keys.
  • It makes iteration easier.

4. While Loop

Definition:

A while loop executes a block of code repeatedly as long as the given condition is true.

A while loop is used to execute a block of code repeatedly as long as the given condition is true.

Syntax:

while (condition) {
    // Code to be execute
}

Example:

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Output (Console):

1
2
3
4
5

Important Points:

  • Condition is checked before execution.
  • If the condition is false, the loop does not execute.
  • Increment or decrement is required to avoid an infinite loop.

5. Do While Loop

Definition:

A do while loop executes the block of code at least once before checking the condition.

Syntax:

do {
    // Code to execute
} while (condition);

Example:

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

Output (Console):

1
2
3
4
5

Important Points:

  • Code executes before checking the condition.
  • It executes at least once.
  • It is also called an exit-controlled loop.

Note:

While = Check first, Execute later.
Do While = Execute first, Check later.
