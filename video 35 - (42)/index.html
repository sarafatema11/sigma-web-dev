CSS Transforms : (Mostly Used For Navbar.)

there are 2 types of transforms

  1. 2D Transforms
  2. 3D Transforms

  1. 2D Transforms

    2. means hum change kerna chathy hai kisi bhi object ko in (2D) two dimenstion space like Translate, Skew, Rotate, Scale etc.jo bhi hai wo hum kr sakte hai.
    Because its 2D, transformations are applied only in the X (horizontal) and Y (vertical) dimensions.

    syntax: transform: function(values);

    Where function can be translate, rotate, scale, skew, etc.

    1. Rotate Property:

      1. transform: rotate(40deg);

        2. 40 degree box move roate hojayega.

      2. transform: rotate(0.25turn);

        3. ye 90 degree move hogya hai.

      3. transform: rotate(0.5turn);

        4. ye 180 degree pr roate ho jayega.

        Turn : means ek baar isko ghuma kr wapas wahi pr rakh diya like 360 degree ka roataion.

      4. transform: rotateX(40deg);

        5. roate x means ye roate hoga x axsis k around
        ye x-axsis k about 40 degree rotate hogaya.

      5. transform: rotatey(9deg);

        6. ye y-axsis k about 9 degree rotate ho jayega.

      6. transform: rotatez(9deg);

        7. ye z-axsis k about roate ho jayega.

    2. Scale Property:

      1. transform: scale(1.6);

        2. ye 1.6 times scale se bada big hogaya hai.

      2. transform: scalex(1.6);

        3. agar me chaho sirf x-axsis me ho to x me 1.6 times se big ho jayega.

      3. transform: scaley(1.6);

        4. or aagar chaho y-axsis me ho to abb y-axsis me 1.6 times se big ho jayega.

      4. transform: scalez(1.6);

        5. ye z-axsis me 1.6 times se big ho jayega.

      5. Scale3d()

        6. jab aap scale 3d krte ho to ek scale 3d transformation jo hai wo apply ho jata hai.

    3. Skew Property:

      1. transform: skew(5deg);

        2. ye 5 degree se Skew ho jayega.
        Skew means samajh lo kisi ne upr se or kisi ne neeche se pakad kr force laga diya kheech diya.like may be kaju katli shape.

      2. transform: skewy(34deg);

        3. y-axsis me bhi kr sakte ho app skew.

        z-axsis me skew nahi hota always remember. skew z-axsis k liye apply nhi hota hai.

    4. Translate Property : (Mostly Used Property)

      1. transform: translatex(34px);

        2. ye 34 pixel translate ho jayega.

      2. transform: translate(34%);

        3. ye jo is ki width hai uska (34%) 34 percent translaate ho jayega.

      3. transform: translate(100%);

        4. ye 100% percent se translate ho jayega.

      4. transform: translatey(100%);

        5. dd ye y me translate kro to neeceh aa jayega.

    5. Multiple Transforms Property :

      6. kabhi kabhi hamein ek se zyada Transform proprty lagani hoti hai tab hum aisa write kr sakte ya see below:

      1. transform: translatey(100%) skew(40deg) translateX(45%);

        2. is me Translate x & y axsis or skew proprty hai.

        if i want to hide navbar i use below proprty.

      2. transform: translatey(-100%) skew(40deg) translateX(45%);

        3. is me bas 100 k samme - minus laga diya hai or margin or padding zero krdi hai.
        thats why box hamara hide hogaya hai.

    6. Rotation point

      1. transform: rotate(0.125turn);

        2. ye 45 degree se turn kr raha hai.

      2. transform-origin:-50% -50%;

        3. jo Default property hoti hai transform origin ki wo -50% -50% hoti hai. means center hoti hai.

      3. transform: rotate(55deg);

      4. transform-origin:-0% -0%;

        5. mein ne rotate 55 degree kr diya or transform origin 0 kkr diya jaise jaise mein degree ka number increase kroga waise hi rotation is points zero k about/ around ho raha hai.
        zero zero k about jo ki origion hai.

  2. 3D Transforms :

    1. means head (3d) 3 dimension kaam karta hai.
    2. means ek additional axsis hamare pass hota hai like z-axsis jis ki wajah se 3d 3dimension mein ek object ko manipulate ker sakta hai.
