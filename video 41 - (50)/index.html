CSS Filters Properties:

  1. filter:blur(10px);

    1. is se aap ki image blur hojayegi.
    2. aap jitni zyadi value rakhoge utna zyada wo image ko blur karega. ex: bluur value: 7px, 10px etc.

  2. filter: brightness(122%);

    1. give brightness to the image based on values.
    2. is me px use nhi hota hai remember always.

  3. filter:contrast(0.5)

    1. is use agar mujhe contrast increase krna hai to 0(zero) se 1 (one) tak valuee de sakte hai hum.
    2. contrast me hum percentage (%) bhi laga sakte hai.
    3. agar mujhe contrast badana increase krna hai to 0 zero / ya us se bhi big vlaue de sakti hu.
    4. using this we can cahnge the contrast value.

  4. filter: drop-shadow(16px 16px 10px black);

    1. give shadow to the image
    2. hum shadow ka colour khud decide kr sakte hai.
    3. shadow drop kr deta hai.

  5. Multiple Filters:

    1. filter: brightness(122%) contrast(1.5);

      1. for multiple filters we can use this method .
      2. space de kr hum multiple filters laga sakte hai just like classes .

    2. filter: brightness(122%) contrast(74%);

      1. in contrast we can also use percentage (%).

  6. filter: grayscale(100%); filter: grayscale(20%);

    1. agr is ki value 100% krdiya to image puri black & white hojayegi.
    2. or agr 20% is ki value rakhe to image 20% grayscale me convert ho jayegi.

  7. filter: sepia(100%);

    1. purane zamane ki jaise image ho jayegi.

  8. filter: hue-rotate(90deg);

    1. basically image ke colours ko change/rotate karta hai.
    2. Isse image ke original colours different colours mein transform ho jaate hain.
    3. Yahan 90deg ka matlab hai colour wheel ko 90 degrees rotate karna.

      4. See Example:

    4. filter: hue-rotate(0deg); /* Original colours */
    5. filter: hue-rotate(90deg); /* Colours change */
    6. filter: hue-rotate(180deg); /* Opposite colours */
    7. filter: hue-rotate(270deg); /* Different colour combination */
    9. filter: hue-rotate(360deg); /* Original colours */

  9. filter: invert(1);

    1. filter: invert(.10);
    2. point laga kr aap thoda bhot usko apne hisab se change kr sakte ho.
    3. it will be converted into Negative image.
    4. bacome a innverted image, all colours will be innverted.
    5. basically image ke colours ko unke opposite colours mein convert karta hai.
    6. for Ex: White → Black ,---, Black → White etc.

  10. filter:opacity(0.6);

    1. agr value iskko zer(0) hogi to image puri hi gayab ho jaye gi.
    2. or agr iski vlaue 1 (one) hogi to puri image visble rahegi.
    3. hum apne hisab se image kitnni dekhna/ transparent hona ye decide kr sakte hai.
