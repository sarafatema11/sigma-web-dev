Mouse Events are below :

  1. addEventListener :

    1. addEventListener() is used to attach an event handler to an HTML element.

  2. click ():

    1. ek bar button pr click kr diya to conntent change ho jayega.
    2. Ex: 

      3.         button.addEventListener("click", ()=>{ 
         // alert("I was Clicked. yayy!!")

        document.querySelector(".box").innerHTML = " Yayy you were clicked  Enjoy your click!"
})

  3. dbl click - measn (double click) :

    1. do bar button pr click kra to content show hoga.
    2. Ex:-

      3.         button.addEventListener("dblclick", ()=>{  

        document.querySelector(".box").innerHTML = " Yayy you were clicked  Enjoy your click!"
})

  4. mouse down :

    1. Jab tum button par click karoge, tab mousedown event bhi execute hoga.
    2. jab aap ne mouse k button ko click kra.
    3. EX:

      4.         button.addEventListener("mousedown", () => {
        console.log("Mouse button pressed")
        })

  5. mouse enter :

    1. Jab tum button k pass mouse le kr jaoge to mouse enter execute ho jayega. or color change ho jayega.
    2. Ex:

      3.         button.addEventListener("mouseenter", () => {
        document.querySelector(".box").style.color ="red"
        })

  6. mouse leave :

    1. Jab tum button k pass se mouse pointer le kr jaoge tab mouse leave execute ho jayega. style change ho jayega.
    2. Ex:-

      3.     button.addEventListener("mouseleave", () => {
    document.querySelector(".box").style.color ="blue"
    })

  7. mouse out:

    1. Jab mouse pointer button ke upar hoga, kuch change nahi hoga. Jaise hi mouse pointer button se bahar jayega (mouseout). .box ka background color pink ho jayega.
    2. Ex:

      3.  button.addEventListener("mouseout", () => {
 document.querySelector(".box").style.backgroundColor ="pink"
})

  8. Context menue :

    1. Button par mouse pointer lekar jao. then Right-click karo. then see alert box ayega.
    2. Ex:

      3.   button.addEventListener("contextmenu", () => {
  alert("Dont hack us by Right click Please")
  })

Keyboard event:

Keyboard Events means jab bhi hum keyboard par koi key press ya release karte hain, tab JavaScript mein keyboard events fire hote hain.

  1. Keydown :

    1. Jab bhi hum keyboard ki kisi key ko press karte hain, tab keydown event fire hota hai.
    2. Keyboard se koi bhi key press karo. Console mein "jo bhi key press kri wo or us ka code" dono print hoga..
    3. Ex:

      4.    document.addEventListener("keydown", (e) => {
   console.log(e.key, e.keyCode)
   })

  2. keyup :

    1. Jab bhi hum keyboard ki kisi key ko press karne ke baad chhodte (release karte) hain, tab keyup event fire hota hai.
    2. Ex:

      3.    document.addEventListener("keyup", (e) => {
   console.log(e.key, e.keyCode)
   })

  3. key press :

    1. Jab user keyboard ki kisi key ko press karta hai, tab keypress event fire hota hai. Ye mainly character keys (jaise A, B, 1) ke liye use hota tha.
    2. Deprecated = Purana feature, jiska use ab avoid karna chahiye.
