Asynchronous Javascript :

Asynchronous ka matlab hai kuch tasks background mein handle ho sakte hain aur JavaScript unka wait kiye bina aage ka code execute kar sakta hai.

Why we use Asynchronous JavaScript ?

    Ex :

  1. Maan lo tum ek website bana rahe ho.
  2. Website ko server se users ka data fetch karna hai.
  3. Data aane mein 5 seconds lagte hain.
  4. Agar JavaScript poore application ko rok de aur data aane ka wait kare, toh website unresponsive ho sakti hai.
  5. Is problem ko avoid karne ke liye asynchronous JavaScript use hota hai.

Asynchronous JavaScript have 3 important methods :

  1. Callback :

    2. Ek function ko doosre function ke argument ke roop mein pass karna callback kehlata hai.

  2. Promise :

    3. Promise ek object hai jo batata hai ki asynchronous task future mein successfully complete hoga ya fail.

  3. Async/Await :

    4. Async/Await Promise ke saath asynchronous code likhne ka easy tarika hai.

Async Keyword in Javascript :

  1. async JavaScript ka ek keyword hai, jo kisi function ke aage lagaya jata hai.
  2. async ka matlab hai ki function hamesha ek Promise return karta hai. Promise ka result future mein milta hai, turant nahi.

    3. Ex :

    async function getData() {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve(455) // random value de denge.
        }, 3500); 
    })
}

console.log("Loading Modules")
console.log("Do Something Else")
console.log("Load Data")

let data = getData()

console.log(data)

console.log("Process Data")
console.log("task 2");

    Output :

     Loading Modules
 Do Something Else
 Load Data
 Promise {}
 Process Data
 task 2

    Code Explain :

    1. async function getData() — async ki wajah se function Promise return karta hai.

2. new Promise() — Ek Promise create hota hai, jo future mein result dega.

3. setTimeout() — 3500 milliseconds yaani 3.5 seconds baad andar ka code chalega.

4. resolve(455) — Promise successful ho jayega aur uska result 455 hoga.

5. let data = getData() — Function call hota hai aur data mein Promise store hota hai, 455 nahi.

6. console.log(data) — Promise abhi complete nahi hua, isliye output mein Promise {  } dikhta hai.

7. Process Data aur task 2 — Ye dono print ho jaate hain, kyunki JavaScript Promise ka wait nahi kar rahi.

8. (3.5 seconds) baad Promise complete ho jaata hai aur uski value 455 ho jaati hai. Lekin humne value print nahi karwayi.

Await Keyword in Javascript :

  1. JavaScript mein await ek keyword hai jo Promise ke complete hone aur uska result aane tak wait karta hai.
  2. await ko normally async function ke andar use kiya jata hai.

    3. Ex :

    async function getData() {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve(455) // random value de denge.
        }, 3500);
    })
}

async function main() {

    console.log("Loading Modules")
    console.log("Do Something Else")
    console.log("Load Data")

    let data = await getData()

    console.log(data)

    console.log("Process Data")
    console.log("task 2")
}

main();

    Output:-

    Loading Modules
Do Something Else
Load Data

// 3.5 seconds wait

455
Process Data
task 2

    Code Explain :

    1. async function getData() — Ek async function banaya, jo Promise return karta hai.

2. new Promise() — Ek Promise create kiya, jo future mein data dega.

3. setTimeout() — 3500 milliseconds yaani 3.5 seconds ka delay lagaya.

4. resolve(455) — 3.5 seconds baad Promise complete hoga aur 455 value dega.

5. async function main() — Ek async function banaya, jiske andar hum await use kar rahe hain.

6. console.log() — Starting ki teen lines turant print hongi.

7. let data = await getData() — Yahan await Promise ka wait karega. Jab tak Promise complete nahi hota, main() function ka aage ka code execute nahi hoga.

8. console.log(data) — Promise complete hone ke baad 455 value data mein store hogi aur yahan 455 print hoga.

9. Process Data aur task 2 — 455 print hone ke baad ye dono lines execute hongi
