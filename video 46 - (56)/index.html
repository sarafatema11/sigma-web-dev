    JavaScript Operators

    1. Arithmetic Operators

    Arithmetic operators are used to perform mathematical operations.

    No. Operator Symbol Definition Example
    1 Addition + It is used to add two values. 10 + 5 = 15
    2 Subtraction - It is used to subtract one value from another. 10 - 5 = 5
    3 Multiplication * It is used to multiply two values. 10 * 5 = 50
    4 Division / It is used to divide one value by another. 10 / 5 = 2
    5 Modulus % It is used to find the remainder after division. 10 % 3 = 1
    6 Exponentiation ** It is used to raise a number to the power of another number. 2 ** 3 = 8
    7 Increment ++ It is used to increase a variable's value by 1. a++
    8 Decrement -- It is used to decrease a variable's value by 1. a--

    2. Assignment Operators

    Assignment operators are used to assign values to variables.

    No. Operator Symbol Definition Example
    1 Assignment = It is used to assign a value to a variable. a = 10
    2 Addition Assignment += It adds a value to a variable and assigns the result. a += 5
    3 Subtraction Assignment -= It subtracts a value from a variable and assigns the result. a -= 5
    4 Multiplication Assignment *= It multiplies a variable by a value and assigns the result. a *= 5
    5 Division Assignment /= It divides a variable by a value and assigns the result. a /= 5
    6 Modulus Assignment %= It finds the remainder and assigns the result. a %= 5
    7 Exponentiation Assignment **= It raises a variable to a power and assigns the result. a **= 2

    3. Comparison Operators

    Comparison operators are used to compare two values and return true or false.

    No. Operator Symbol Definition Example
    1 Equal == It checks whether two values are equal. 10 == 10
    2 Strict Equal === It checks whether two values and their data types are equal. 10 === 10
    3 Not Equal != It checks whether two values are not equal. 10 != 5
    4 Strict Not Equal !== It checks whether two values or their data types are different. 10 !== "10"
    5 Greater Than > It checks whether the left value is greater than the right value. 10 > 5
    6 Less Than < It checks whether the left value is less than the right value. 5 < 10
    7 Greater Than or Equal >= It checks whether the left value is greater than or equal to the right value. 10 >= 10
    8 Less Than or Equal <= It checks whether the left value is less than or equal to the right value. 5 <= 10

    4. Logical Operators

    Logical operators are used to combine or reverse conditions.

    No. Operator Symbol Definition Example
    1 Logical AND && It returns true only when both conditions are true. (10 > 5) && (10 > 8)
    2 Logical OR || It returns true when at least one condition is true. (10 > 5) || (5 > 10)
    3 Logical NOT ! It reverses the result of a condition. !(10 > 5)

    5. Conditional (Ternary) Operator

    No. Operator Symbol Definition Example
    1 Ternary ? : It checks a condition and returns one of two values depending on whether the condition is true or false. age >= 18 ? "Adult" : "Minor"

  2. JavaScript Comments

    3. 1. Single Line Comment (//)

    Definition: Single line comments are used to write a comment in one line. They are not executed by the JavaScript browser.

    Example:

    <script>
// This is a single line comment
let a = 10;
console.log(a);
</script>

    2. Multi Line Comment (/* */)

    Definition: Multi line comments are used to write comments in multiple lines. They are not executed by the JavaScript browser.

    Example:

    <script>
/*
This is a multi-line comment.
It is used to write multiple lines.
*/
let a = 10;
let b = 20;
console.log(a + b);
</script>

  3. JavaScript Conditional Statements

    4. Definition: Conditional statements are used to perform different actions based on different conditions. They execute code according to whether a condition is true or false.

    1. if Statement

    Definition: The if statement is used to execute a block of code only when the given condition is true.

    Example:

    let a = 10;

if(a > 5){
    console.log("True");
}

    2. if-else Statement

    Definition: The if-else statement is used to execute one block of code if the condition is true and another block if the condition is false.

    Example:

    let a = 10;

if(a > 15){
    console.log("True");
}
else{
    console.log("False");
}

    3. else-if Statement

    Definition: The else-if statement is used to check multiple conditions one by one.

    Example:

    let marks = 75;

if(marks >= 90){
    console.log("Grade A");
}
else if(marks >= 60){
    console.log("Grade B");
}
else{
    console.log("Grade C");
}

    4. Nested if Statement

    Definition: A nested if statement means writing an if statement inside another if statement.

    Example:

    let a = 10;
let b = 20;

if(a < b){
    if(b > 15){
        console.log("True");
    }
}

    5. Switch Statement

    Definition: The switch statement is used to execute one block of code from multiple choices based on a given expression.

    Example:

    let day = 2;

switch(day){

    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    case 3:
        console.log("Wednesday");
        break;

    default:
        console.log("Invalid Day");
}

    6. Ternary Operator

    Definition: The ternary operator is a short way of writing an if-else statement. It checks a condition and returns one of two values.

    Example:

    let age = 20;

let result = (age >= 18) ? "Adult" : "Minor";

console.log(result);
