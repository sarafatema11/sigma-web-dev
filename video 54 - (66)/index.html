DOM :

Dom : Document object Model is a Browser Api which is access through the javascript.

  1. DOM ek programming interface hai jo HTML document ko ek tree structure (object) mein convert karta hai, jisse JavaScript HTML elements ko access aur change kar sakti hai.
  2. DOM khud JavaScript ka method nahi hai. DOM browser ka API hai, jise JavaScript ke through access karte hain.

  1. DOM Methods :

    2. Methods ka use HTML elements ko select ya manipulate karne ke liye hota hai.

            document.getElementById("demo");
        document.querySelector("h1");
        document.querySelectorAll("p");
        document.createElement("div");
        document.removeChild(element);

  2. DOM Properties :

    3. Properties se hum HTML elements ki information le ya change kar sakte hain.

    element.innerHTML;
element.innerText;
element.textContent;
element.id;
element.className;
element.style;

  3. DOM Events :

    4. Events ka matlab hai user ke actions, jaise click karna, keyboard press karna etc.

        element.onclick;
    element.addEventListener("click", function() {
    console.log("Button clicked!");
});

  4. DOM Types :

    5. DOM mein different types ke nodes hote hain: -

     1. Document Node: Pura HTML document.
 2. Element Node: HTML tags, jaise h1, p, div.
 3. Text Node: HTML tags ke andar ka text.
 4. Attribute Node: Attributes, jaise id, class.

  5. DOM Functions :

    6. DOM mein hum JavaScript functions ka use bhi karte hain, jaise :

        function changeText() {
    document.querySelector("h1").innerText = "Hello!";
    }

  1. DOM : document object Model

    1. DOM ka use HTML page ko access aur manipulate karne ke liye hota hai.

  2. BOM : browser object Model

    1. BOM ka use browser ko access aur control karne ke liye hota hai.
    2. if u want to work with someone others than the document , then the then browser provide you some additionall object. is called bom.
    3. the function / alert / connfirm / prompt they all are also the part of the bom.
