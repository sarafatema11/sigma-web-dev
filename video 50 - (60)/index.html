  7. Escape Sequence Character:

    8. Escape Sequence Characters in JavaScript are special characters used with a backslash (\) to perform specific tasks inside strings.
     | Escape | Meaning      |
 -------------------------
 | `\n`   | New line     |
 | `\t`   | Tab space    |
 | `\'`   | Single quote |
 | `\"`   | Double quote |
 | `\\`   | Backslash    |
 -------------------------

    Example:-

    let text = "Hello\nRahul"        
console.log(text);

    1. output print on browser is :-
      Hello
      Rahul
