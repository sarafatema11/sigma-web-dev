Css Object fit & object position properties:

  1. ek container k under image ko aisa rakhna hota hai such that uski width puri cover hojaye
  2. ya phir wo puri is box k under aapne aspect ratio ko maintain kerte hoye box me fit aajaye.
  3. that's why we use object fit & object position properties.

Mostly used Properties in:- object-fit :

  1. cover

  2. contain

  3. fill - (is by deafult property)

  1. object-fit:cover;

    1. ye img ko cover kr dega but khahi na khahi se img ko cut kr dega object cover tabhi img cover kr payegi box ko.
    2. is box ka aspect ration maintain kro cover krlo. or isko apne parents ki height width means jo container hai us se koi matlab nhi hai ye sirf img ko cover krega.

  2. object-fit: contain;

    1. puri img dekhao or space bachi rahene do we use object-fit contain.
    2. is img me height width ko pura containt krega img puri dekhegi

  3. object-position: top right;

    1. object fit cover me konsa positiion cut hoga or konsa position dekhega ye aap khud decide kr skate ho.
    2. is ne mujhe top right wala pura posion dekh diya or left side wala cut kr diya.

  4. object-position: bottom right;

    1. is ne mujhe right side se bottom ki puri image dekha di.

  5. object-fit: fill;

    1. ye use krne se jo mein ne width or height di hai wo is me lag jjayehi image mein.
    2. puri immage dekhegi but distorted dekhegi.

  6. object-fit: scale-down;

    1. image ka size small ho jayega.

  7. object-fit: none;

    1. agr image reset krna ho to aap none kr sakte ho.

  8. object-position: 10px 20px;

    1. object position change kr sakte ho top bottom left right se
    2. object fit property mme ye bhi specify kr sakte ho ki kitni kitni dori pr aap image ko dekhna chathy ho.

  9. background-image: url(image address/ link);

    1. image ka url ka use krte huye hum background de sakte hai container ko style sheet me
    2. is container me backgroundimage set krdo.

  10. background-position: top right;

    1. image ka background position top right side se dekhe.

  11. background-position: center center;

    1. image ka center position dekhega top-bottomm se or left-right se. without image ka aspect ratio change kare.

  12. background-image:urll(small size image link)

    1. small size image ki link daloge to wo y axis me repeat hogi.
    2. x axis me or zyada repeat hoti but abhi hum jo link use kre us me sirf y axis me image repeat hori.

    (mostly used this repeat property):

  13. background-repeat: no-repeat;

    1. image repeat ko remove krne k liye hum repeating property ka use krte hai.
    2. ye property use krne se na x mein repeat hoga na y me repeat hoga.

  14. background-repeat: repeat-x;

    1. agr background image ka width chota hua to wo x me repeat hoga y me repeat nahi hoga.

  15. background-clip: border-box;

    1. background-clip me aap border-box / padding-box likh sakte ho.
