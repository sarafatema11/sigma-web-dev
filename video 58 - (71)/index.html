Events & Properties using DOM :

  1. innerText method :

    1. kabhi kisi element k under ka text pata lagane k liye is ka use krte hai.

  2. InnerHtml :

    1. inner html me container k under jo html hai wo milti hai.
    2. Returns the HTML content inside an element.
    3. It does not include the element's own opening and closing tags.

      4. Ex :

      console.log(document.querySelector(".container").innerHTML)

      output:-
      Hey I am a box
      Hey I am a box

  3. OuterHtml :

    1. Returns the complete HTML of an element.
    2. It includes the element's own opening and closing tags along with its inner content.

      3. Ex :

      console.log(document.querySelector(".container").outerHTML)

      output:-

      
        
       Hey I am a box 
      
        
       Hey I am a box

    3. container k sath sath us k under k elements bhi mil gye.

  4. TagName property :

    1. jo element mein ne select kiya hai wo ek div hai.

      2. Ex :

                console.log(document.querySelector(".container").tagName)
    

      output:- DIV

    2. It works only with HTML elements.
    3. In HTML documents, it returns the tag name in uppercase.

  5. Node Name property:

    1. jo element mein ne select kiya hai wo ek div hai.

      2. Ex :

                console.log(document.querySelector(".container").nodeName)
    

      output:- DIV

    2. It works with elements, text nodes, comments, etc.
    3. For HTML elements, it returns the tag name in uppercase.

  6. Text Content :

    1. us k under jo text content hai wo mil jayega.

      2. Ex :

               console.log(document.querySelector(".container").textContent)

      output:- Hey I am a box , Hey I am a box

  7. hidden property :

    1. hide name k attribute div me laga doge to wo content hide ho jayega.

      2. Ex :

              console.log(document.querySelector(".container").hidden = true)

      output:- //true ayega output.

    2. jo mera container hai us k under hidden laga dega. ye krne se elements hide ho jayegi.

  8. Change innerHtml :

    1. we can change inner html.
    2. using this kisi bhi element ki inner html change kr sakte hai.

      3. Ex :

       console.log(document.querySelector(".box").innerHTML = "Hey i am harry")

      output:- Hey i am harry

Insertion Methods :

  1. .append :

    1. Element ke andar sabse last mein content add karta hai.
    2. Meaning: Container ke andar sabse neeche div add hoga.
    3. ye jab bhi use krte tab wo end me dekhen ko milta text.

      4. ex:

          document.querySelector(".container").append(div);

  2. .before

    2. ye krne se hum ne jo created name ka div banaya hai wo div container se phele means container k upr ajayega.
    3. u can see on inspect webpage & inspect & elements see here creted div then container div.
    4. Selected element ke just pehle content add karta hai.

      5. Ex :

          document.querySelector(".container").before(div);

  3. .after :

    1. Selected element ke just baad content add karta hai.
    2. ye krne se before k just ulta hoga.
    3. means phele container div ajayega. then creted name div ajyega.

      4. Ex :

          document.querySelector(".container").after(div);

  4. .prepend :

    1. Element ke andar sabse starting mein content add karta hai.

      2. Ex :

            document.querySelector(".container").prepend(div);

    2. Meaning: Container ke andar sabse upar div add hoga.
    3. ye append method k just ulta hai us me text last me neeche ajata tha is me sab se upr jayega text.
    4. is me text sab se upr ajayega jo hum ne div.created name ka banay hai.

  5. replacewith :

    1. Ye method kisi existing element ko remove karke uski jagah new element add karta hai.

    2. ex:

          document.querySelector(".container").replaceWith(div);

Adjacent :

JavaScript DOM mein adjacent elements ka matlab hota hai kisi selected element ke just pehle ya just baad content insert karna.

  1. insertAdjacentHTML() :

    2. HTML code insert karta hai.

  2. insertAdjacentText() :

    3. Plain text insert karta hai.

  3. insertAdjacentElement() :

    4. Ek HTML element insert karta hai.

    insertAdjacentHTML() ke 4 positions :

    there are below :

    1. beforebegin :

      1. insert HTML immediatly before element.

    2. afterbegin :

      1. insert HTML into element at the beging

    3. beforeend :

      1. insert HTML into element at the end.

    4. afterend :

      1. insert HTML immediatly after html.

  4. Easy trick :

    5. see this to remember Adjacent insertion in container me kidhhr hota.

    Easy Trick:
- Beforebegin = Container ke bahar, upar.
- Afterbegin = Container ke andar, sabse upar.
- Beforeend = Container ke andar, sabse neeche.
- Afterend = Container ke bahar, neeche.

        2. Ex :

           console.log(document.querySelector(".container").classList.toggle("red"))

      2. output:- style pply krega ya removve kregga outpput: true false me ayega or css add ya remove kr sakte apn.
