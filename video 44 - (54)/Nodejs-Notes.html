Node.js Short Notes :

1. What is Node.js?

Node.js is a JavaScript runtime environment that allows us to run JavaScript outside the browser.

2. Browser vs Node.js

  • Browser JavaScript runs inside the browser.
  • Node.js runs JavaScript outside the browser.
  • Node.js is mainly used for backend development.

3. Browser Functions Not Available by Default in Node.js

  • alert() ❌
  • prompt() ❌
  • confirm() ❌
  • document ❌
  • window ❌
  • localStorage ❌
  • sessionStorage ❌
  • DOM ❌

4. JavaScript Features Available in Both (js and nodejs)

  • console.log()
  • console.error()
  • console.warn()
  • setTimeout()
  • setInterval()
  • Promise
  • Array
  • Object
  • JSON.parse()
  • JSON.stringify()

5. Node.js Modules

  • fs - Read and write files.
  • http - Create HTTP servers.
  • path - Work with file paths.
  • os - Get operating system information.
  • process - Get process information.
  • readline - Take input from terminal.

6. How to Run JavaScript in Node.js?

Step 1: Create a file named app.js and new.js etc

Step 2: Write JavaScript code:

console.log("Hello World");

Step 3: Open the VS Code terminal and run:

node app.js

7. Important Points

  • Node.js does not have HTML body or head.
  • Node.js uses .js files.
  • alert(), prompt() and confirm() are not available by default.
  • Use readline to take input in Node.js.
  • Node.js is used for backend development.
