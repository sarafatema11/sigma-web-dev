npm (Node Package Manager)

1. What is npm?

npm stands for Node Package Manager. It is used to install, manage and share JavaScript packages (libraries).

2. Why do we use npm?

  • To install packages and libraries.
  • To manage project dependencies.
  • To save time using ready-made code.
  • To manage project scripts.
  • To use third-party libraries in our projects.

3. How to Install npm?

  • npm comes bundled with Node.js.
  • When we install Node.js, npm is automatically installed with it.
  • We don't need to install npm separately in normal installations.

4. Important npm Commands

Check Node.js version:

node -v

Check npm version:

npm -v

Create a Node.js project:

npm init -y

Creates a package.json file automatically.

Install a package:

npm install express

Installs the Express.js package.

Uninstall a package:

npm uninstall express

Removes the installed package.

Install all project dependencies:

npm install

Installs all dependencies listed in package.json.

Update packages:

npm update

Updates installed packages according to the allowed version ranges.

5. What is package.json?

package.json is a file that stores project information, dependencies and scripts.

  • Project name
  • Project version
  • Dependencies
  • Scripts
  • Project information

6. What is node_modules?

node_modules is a folder where all installed npm packages and their dependencies are stored.

7. What is package-lock.json?

package-lock.json stores the exact versions of installed dependencies to maintain consistent installations across different systems.

8. What are npm Packages?

Packages are reusable pieces of JavaScript code that we can install and use in our projects.

Examples:

  • Express.js - Used to create backend servers.
  • React - Used to build user interfaces.
  • Axios - Used to make HTTP requests.
  • Mongoose - Used to work with MongoDB.

9. What is npm install -g?

npm install -g package-name

Installs a package globally so it can be used from different projects (depending on the package).
