Shadow:

syntax:

box-shadow: h-offset v-offset blur spread color inset;

  1. h-offset & v-offset : (means horizontal vertical shaadow kitni door hogi.) determine shadow horizontal & vertical direction/position.
  2. blur : (means jitni zyada value rikhoge utni zyada blur hoga.) the larger the vale, blurere the shadow.
  3. spread :(shadow size big small) Expand & shrink the shadow.
  4. color : (give color of the shadow.) define shadow color.
  5. inset : (aap kitni under shadow rakhna chathy ho.) make the shadow inner.

Outline:

is a line that is drawn around element.

syntax :

outline : width style color;

  1. width: sets the outline width.
  2. style: determine the style of the outline. ex: dashed, dotted,solid etc.
  3. color: sets the outline color.
