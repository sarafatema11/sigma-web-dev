diference between Transition & Animation:

  1. Transition:

    2. Transition mein bhi aap ek se zyada property change kr sakte ho but in animation.
    simple property liye animation use kro.

  2. Animation:

    1. Animation ki help se Aap ek se zyada property change kr sakte ho.
    2. or animation mein aap defined ker sakte ho konse property khaha se khaha tak jayegi , kitne time tak jayegi,or kon konse Keyframes honge.
    3. or agar aap ko complex animation banane hai jo ki repeat hore alag alag element me lagare to aap harryKaAnimation name ka animation bana sakte ho or usko alag alag jagah use kr sakte ho.

To make Animation Followings these Steps:

Animation banane k liye keyframe and Animation name likho animation name means like a vairable.

syntax:

Ex: @keyframes harryKaAnimation{ from{} to {} }

Animation Property:

  1. animation-duration:3s

    1. (kitni der tak chalega aap ka animation)

    2. 3s means (3 second)tak chalega ye animation duration.
    3. ye jo hai 1000px translate kr k wapas aa jara hai.

  2. animation-iteration-count:3;

    1. itni baar chalna chaiye ye.
    2. animation-iteration-count:3; means ye 3 baar repeat hoga.

  3. animation-iteration-count: infinte;

    4. animation-iteration-count:infinite; krne se ye chalta rahega animation.

  4. animation-timing-function:ease-out;

    1. ease

    2. ease-in

    3. ease-out

    4. ease-in-out

      5. is se hum hamara animationn ka timing function change kr sakte hai.

  5. animation-delay:1s;

    1. page reload karoge to animation 1 second k baad start hoga. or repeat hota jayega.
    2. kitni der k baad start hoga animation if 11s lagaa do to 11 second k baad start hoga animation.

  6. animation-direction: reverse;

    7. animation right side se start hogi.

  7. animation-direction: alternate-reverse;

    8. animation right se left ko ja kr wapas rightside aa jayegi.

  8. animation-play-state:

    1. paused

      2. animation ko beech me se aap paused kr sakte ho

    2. runing

  9. Animation-fiiled-mode:

    1. forwards
    2. backwards
