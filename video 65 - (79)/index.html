    JavaScript – isNaN() Function :

    Definition:
    isNaN() means "Is Not a Number". It checks whether a given value is Not a Number. Syntax: 
    isNaN(value)
    Examples: 
    isNaN(10);       // false
isNaN("hello");  // true
isNaN("123");    // false
isNaN("abc");    // true
    Important:
    • Number input → false
    • Non-numeric input → true

    Why do we use isNaN()?
    To validate user input and prevent invalid values during mathematical calculations.

    Example: (same jo upr use kra hum ne) 
    let a = prompt("Enter first number");
let b = prompt("Enter second number");

if (isNaN(a) || isNaN(b)) {
    throw new Error("Invalid input!");
}

let sum = Number(a) + Number(b);
console.log(sum);
    Remember:
    isNaN() → Checks if a value is NOT a Number.
    !isNaN() → Checks if a value can be treated as a Number.

2 Types of Errors in JavaScript

1. Custom Error (Throwing Errors) :-
When we manually create and throw an error based on a condition, it is called a Custom Error.
Example: 

let a = prompt("Enter a first number ")
let b = prompt("Enter a second number ")

if (isNaN(a) || isNaN(b)) {
    throw SyntaxError("Sorry this is not allowed")
    //hum istarah se js me bhot sare errors hote hai usko throw kr sakte hai.
}

console.log("The sum of ", sum)

We can use custom errors for input validation, such as checking user input with the isNaN() function.

2. Error Handling (Handling Existing Errors) :-
Sometimes errors occur unexpectedly due to external factors or mistakes in our application.

For example:
  • Network request fails.
  • Unexpected data is received from an API.
  • Server is unavailable.
We can handle these errors using try-catch.
Example: 

let a = prompt("Enter a first number ")
let b = prompt("Enter a second number ")

if (isNaN(a) || isNaN(b)) {
    throw SyntaxError("Sorry this is not allowed")
}

let sum = parseInt(a) + parseInt(b)

try {
    console.log("The sum of ", sum*x) 
//ye try kro ye chal jata hai to theek hai warna catch msg print kro.
} catch (error) {
    console.log("Error aa gaya bhai") 
// ye print hoga error with out red color mein like print on console screen like a normal msg..
}

We can also handle errors by:
  • Retrying the request.
  • Showing an error message to the user.
  • Providing an alternative solution.
Remember: Custom Error = Manually generate an error using throw. Error Handling = Handle errors using try-catch.

**Note:** Dono concepts ek saath bhi use ho sakte hain. Custom error ko bhi `try-catch` se handle kar sakte hain.
