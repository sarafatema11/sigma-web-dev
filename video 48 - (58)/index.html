JavaScript Functions

1. What is a Function?

A function is a reusable block of code that performs a specific task.

Remember: Define once, Call many times.

2. Function Example – nice()

function nice(name) {
    console.log("Hey " + name + " you are nice!");
    console.log("Hey " + name + " you are good!");
}

nice("Rohan");
nice("Shivam");

Here, name is a parameter and "Rohan" is an argument.

3. Function Sum

function sum(a, b) {
    console.log(a + b);
}

sum(3, 5);

Output: 8

Here, a = 3 and b = 5.

4. Return Keyword

return keyword sends a value back from the function to the caller. 

function sum(a, b) {
    return a + b;
}

let result = sum(3, 5);

console.log(result);

Output: 8

Remember: console.log() prints a value, while return sends a value back.

5. Reusable Function

function sum(a, b) {
    return a + b;
}

let result1 = sum(3, 5);
let result2 = sum(7, 5);
let result3 = sum(3, 13);

console.log(result1);
console.log(result2);
console.log(result3);

Output: 8, 12, 16

6. Default Parameters

A default parameter is a value given to a parameter when no argument is passed for it. 

function sum(a, b, c = 3) {
    return a + b + c;
}

let result1 = sum(3, 5);
let result2 = sum(7, 5);
let result3 = sum(3, 13, 1);

console.log(result1);
console.log(result2);
console.log(result3);

Output: 11, 15, 17

  • If c is not provided, default value 3 is used.
  • If c is provided, the given value is used.

7. Undefined and NaN

function sum(a, b, c = 3) {
    console.log(a, b, c);
    return a + b + c;
}

let result = sum(3);
console.log(result);

Output: 3 undefined 3

NaN: Not a Number. It appears when a mathematical operation produces an invalid numeric result.

Here, b is undefined, so the sum becomes NaN.

8. Arrow Function

An arrow function is another shorter way to write a function in JavaScript. 

const func1 = (x) => {
    console.log("I am arrow function", x);
};

func1(34);
func1(66);
func1(84);

Output:

I am arrow function 34
I am arrow function 66
I am arrow function 84

9. Function Invocation

Function invocation means calling a function to execute its code. 

function greet() {
    console.log("Hello!");
}

greet();  // Function Invocation

10. Important Points to Remember ⭐

  • Function = Reusable block of code.
  • Parameter = Variable receiving a value.
  • Argument = Actual value passed to a function.
  • return = Sends value back to the caller.
  • Default Parameter = Default value of a parameter.
  • Arrow Function = Shorter function syntax.
  • Function Invocation = Calling a function.
  • Undefined = Value not assigned.
  • NaN = Not a Number.
