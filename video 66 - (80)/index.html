prototype :-

  1. javascript object have special property is called prototype.that is either null or refrence another object.
  2. in simple means Prototype allows one object to access the properties and methods of another object.
  3. hum prototype isliye banate hai q ki hum prototypal Inheritance kr paye.

Prototypal inheritance :-

  1. when we try to read a property from a protype and its missing, javascript automatically take it from the prototype . this is called " Prototypal Inheritance ".

Setting Prototype :-

  1. we can set prototype by setting _ _prototype _ _ , now if we read a prototype from the object which is not in object and is present in the prototype, javascript will take it from protype.
  2. Setting Prototype means connecting one object to another object so that the first object can access the properties and methods of the second object.
  3. Ek object ko doosre object ka prototype banana.

from the prototype :-

  1. if we have a method in object, it will be called from the object. if its missing in object and present in prototype, its called " From the prototype "
  2. From the prototype" means accessing or inheriting properties and methods from another object through its prototype.
  3. Ek object apne prototype se properties aur methods leta hai.

Class :-

  2. Class ek design hota hai jiske according hum multiple objects create kar sakte hain.

constructor :-

  1. ye hamesha run krega mein jab bhi ek object banaoga.
  2. A constructor is a special method of a class that is automatically called when a new object is created. It is used to initialize object properties.
  3. Constructor ka kaam object create hote hi uski properties ko initial values dena hota hai.
  4. Constructor automatically tab execute hota hai jab class ka object new keyword se create hota hai.

this Keyword :-

Quiz question :-

create a class user and create a few methods along with a constructor ?

Answer:

class User {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    showName() {
        console.log("Name:", this.name);
    }

    showAge() {
        console.log("Age:", this.age);
    }

    greet() {
        console.log("Hello " + this.name);
    }
}

let user1 = new User("Harry", 20);

user1.showName();
user1.showAge();
user1.greet();


output:- 
Name: Harry
Age: 20
Hello Harry
