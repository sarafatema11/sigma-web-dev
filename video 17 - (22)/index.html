Easy definitions : REM & EM :

REM (Root Em): 1rem is equal to the font size of the root (html) element. Example: If html font-size is 16px, then 1rem = 16px. EM: 1em is equal to the font size of the current/parent element. Example: If the parent has font-size: 20px, then 1em = 20px. If the parent has font-size: 20px, then 2em = 40px. Easy to remember: 👉 rem = based on root font size 👉 em = based on parent/current font size
