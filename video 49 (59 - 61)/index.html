JavaScript Project: Faulty Calculator 🧮

Question:

Create a faulty calculator using JavaScript.

Requirements:

  1. It takes two numbers as input from the user.
  2. It performs the following wrong operations:
Original Operator Wrong Operation
+ -
* +
- /
/ **

Important Condition:

The calculator should perform the wrong operation only 10% of the time.

The remaining 90% of the time, it should perform the correct operation.

Task:

Build this faulty calculator using JavaScript.

Hint 💡

  • Use prompt() to take input.
  • Use Math.random() for the 10% condition.
  • Use if-else statements for operations.

eval() in JavaScript

Definition:

eval() is a built-in JavaScript function that executes a string as JavaScript code.

Syntax:

eval(string);

Example:

let x = "10 + 20";
console.log(eval(x));

Output:

30

Can we use eval()?

Yes, we can use eval() for learning and practice.

But we should avoid it in real-world projects because:

  • It can execute malicious code.
  • It creates security risks.
  • It makes debugging difficult.
  • It can affect performance.

Remember:

Avoid eval() in professional JavaScript development. Use safer alternatives.
